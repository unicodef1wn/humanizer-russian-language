# humanizer-russian-language
Скилл для Claude, удаляющий из текста на русском языке признаки искусственного написания. Обрабатывает лексические и структурные шаблоны, а также антипаттерны чрезмерной гуманизации. Нейтральный стиль изложения, подходящий для длинных постов, аналитических материалов и практических руководств.
